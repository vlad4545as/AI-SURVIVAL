AI SURVIVAL v1.8 — Android-проєкт із хмарним складанням APK

Це НЕ готовий APK. Проєкт містить GitHub Actions workflow, який може зібрати APK у хмарі.

Як зробити це лише з телефона:
1. Увійди або створи акаунт на github.com.
2. Створи новий репозиторій (можна Public або Private).
3. Розпакуй ZIP, а потім завантаж усі файли й папки проєкту в корінь репозиторію. Важливо: не пропусти приховану папку .github.
4. Відкрий вкладку Actions у репозиторії. Якщо GitHub попросить дозволити workflows, натисни дозвіл.
5. Вибери "Build AI SURVIVAL APK" і натисни Run workflow.
6. Коли запуск завершиться успішно, відкрий його сторінку, знайди Artifacts і завантаж AI-SURVIVAL-v1.8-APK.
7. Розпакуй завантажений artifact ZIP. Усередині буде app-debug.apk. Відкрий APK на телефоні, щоб установити.

Примітки:
- Для інсталяції APK Android може попросити дозволити встановлення з цього джерела. Завантажуй і встановлюй APK лише зі свого власного репозиторію та перевіреного запуску GitHub Actions.
- Для Three.js зараз використовується CDN, тому під час гри потрібен інтернет.
- Це базова WebView-оболонка. На телефоні її потрібно перевірити.
- Для публічного поширення потрібні додаткові перевірки, підпис release-версії та тестування.
